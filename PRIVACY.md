# Privacy Policy

Effective date: September 4, 2026

Codex Dev Workflows is an open-source, skills-only plugin. It does not operate a hosted service, collect telemetry, use analytics, store user accounts, or include an MCP server or network client.

## Information handled by the plugin

The workflows are instructions that run inside the user's Codex or ChatGPT environment. When a user invokes a workflow, the host application may provide the workflow with project files, task text, command output, or other context that the user has authorized it to access. This project does not independently upload, retain, or sell that information.

The host application's privacy policy, account settings, retention controls, and security model govern data processed by the host. Users should review those terms before installing or using the plugin.

## Public contributions

Issues, pull requests, discussions, and other content submitted to the public GitHub repository are public. Do not include credentials, private project data, personal information, or confidential logs in public reports.

## Third-party links

The repository links to GitHub and official Codex or OpenAI documentation. Those services have their own privacy policies and terms. This project does not control their data practices.

## Changes and contact

This policy may be updated when the project changes its capabilities. For support questions, see [SUPPORT.md](SUPPORT.md). For suspected security issues, follow [SECURITY.md](SECURITY.md).
