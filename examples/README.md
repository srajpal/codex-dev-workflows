# Examples

Use a skill explicitly when you want a predictable workflow. Replace bracketed text with your project details.

## Start a project

```text
$new-project

I want to build [product] for [users]. The initial outcome is [outcome].
Constraints: [stack, time, budget, privacy, accessibility, deployment].
```

## Test a completed feature

```text
$feature-testing

Test the [feature] I just implemented. The intended behavior is [behavior].
Focus on [edge cases/integration risk]. Do not redesign unrelated code.
```

## Investigate a bug

```text
$bug-investigation

Observed: [actual behavior]
Expected: [expected behavior]
Reproduction: [steps]
Relevant environment/logs: [details]
```

## Use platform guidance

```text
$platform-guidance

This is a [Flutter / TypeScript / Python / Laravel] project. I am working on [task].
```
