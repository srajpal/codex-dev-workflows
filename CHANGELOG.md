# Changelog

All notable changes to this project are documented here.

## [0.3.0] - 2026-09-04

### Added

- General-purpose `$comprehensive-qa` workflow, with game-specific checks included when applicable.
- README workflow snippets for `$session-handoff`, `$resume-interrupted-task`, and `$comprehensive-qa`.
- Dependency-free GitHub Actions validation for plugin metadata, skill front matter, marketplace paths, assets, and accidental local paths.

## [0.2.0] - 2026-09-04

### Added

- `resume-interrupted-task` workflow for recovering interrupted sessions from repository evidence, handoffs, diffs, and test results.
- Plugin icon and logo assets plus marketplace-facing repository/license metadata.

### Note

The new resume workflow follows the library's existing workflow conventions and focuses on recovering interrupted sessions from repository evidence, handoffs, diffs, and test results.

## [0.1.0] - 2026-09-04

### Added

- Skills-only Codex plugin and repository marketplace manifest.
- Ten reusable development workflows.
- Flutter, JavaScript/TypeScript, Python, and Laravel/PHP guidance.
- Installation, examples, contribution, security, compatibility, and roadmap documentation.
