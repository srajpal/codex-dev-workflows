# Privacy Policy

Effective date: September 11, 2026

This policy covers the Codex Dev Workflows package maintained in this repository. It does not cover the host application, services you connect, or modified copies distributed by others.

## Installed plugin

The plugin contains workflow instructions and display assets. It has no hosted backend, telemetry, analytics, user accounts, cookies, MCP server, or network client of its own. Installing it does not create a project-operated storage or data-collection service.

Using the workflows is not an offline-only activity. The host may process prompts, project files, command output, and other context, and an agent may use available tools as authorized. Those tools can read or write files and communicate with services. The plugin does not independently receive that workspace data or control the host's processing, retention, sharing, model training, or deletion settings.

Review the host's and connected services' policies and account controls before sharing sensitive information. Only provide data you are authorized to use, and remove credentials and unnecessary personal information from prompts and reports.

## Support and contributions

GitHub is the project's only support and privacy contact route. If you submit an issue, pull request, discussion, or private security report on GitHub, the project maintainers can see the information you provide and account details made available by the service, such as your username and public profile. This information is used to understand and respond to the submission and maintain the project. Public submissions are public and may be copied or indexed. Use the private reporting guidance in [SECURITY.md](SECURITY.md) for vulnerabilities.

The project keeps support reports on GitHub and does not maintain a separate support-report database or export reports to another support service. Submitted content may remain in GitHub issue history, repository history, notifications, or copies made by others. This policy does not promise a fixed retention period or deletion from third-party copies. To ask about information you submitted, use GitHub's controls or ask the repository maintainers for a private GitHub route through [SUPPORT.md](SUPPORT.md), without repeating sensitive details publicly. The maintainers cannot delete host conversations or connected-service records on your behalf.

## Third-party services

GitHub, the host application, plugin marketplaces, and linked services have their own privacy policies. They may collect information when you visit, install, or use their services. This project's absence of telemetry does not mean those services collect no data.

## Changes

The effective date identifies this version. Changes to the package's data handling should be reflected here before they are released. Forks or modified distributions may behave differently; consult their distributors' policies.
